# 检索纪律

## 只做被点名的事

- 用户说"找论文"→ 只跑论文渠道；说"找代码"→ 只跑 GitHub；说"找书"→ 只跑书库。
- 未指定类型时按论文跑，并提示"也可以查书库"，但不主动查书（书库信息密度低、烧 token）。
- 不跑默认以外的渠道；公开库默认关闭，明确要求才加 `--src=public`。

## 只给题录

- 不打开全文、不下载 PDF、不抓正文；「找」= 标题/作者/来源/年份/被引/链接。
- 用户明确说"读/下"才操作。

## 链接必须验证

- 链接**逐字完整**（只从 `--json` 结果复制，禁止手打/省略/占位符）。
- 外部链接 `curl` 200/30x 算通；**SPA 详情页只看后端接口是否返回正文对象**（页面 200 不代表有效）。
- 同域名抽样验证，不逐条开浏览器；403/429 是反爬/限流，如实标注，不报成 404。
- 验不过 → 条目不丢，退回原文/降级链接并标 ⚠️；宁可不给假链接。

## 合规

- 订阅资源只检索/单篇单本阅读；不批量抓取、不整库转存、不二次分发。
- 文献传递/求助需本人操作，工具不代提交。
- 不读取、不外传任何账号密码/凭据文件。
