# 架构说明

## 目标

一条命令完成"论文 / 代码 / 图书"多源检索；**零第三方依赖**、可移植、失败隔离。

## 分层

```
find.js          入口：参数解析 → 按分组选渠道 → 执行 → 统一渲染（text/md/json）
config.js        配置加载：环境变量 > config.local.js > config.example.js
sources/*.js     每渠道一个适配器：定位 → 抽取 → 取链接，只返回统一 items
chrome.js        受控 Chrome 启停（独立 profile，可无头/有界面）
cdp.js           零依赖 CDP 客户端（Node 原生 WebSocket 直连调试端口）
```

## 为什么手写 CDP

学术站点大多要求"真实页面上下文"（同源 + cookie + 反爬 JS），纯 HTTP 拿不到；
而 `npm install playwright/puppeteer` 在部分环境不可用。Node 原生 WebSocket 足够：
`Runtime.evaluate` 注入抽取脚本 + `Page.navigate` + 轮询等待，约 200 行即可覆盖需求。

## 关键设计取舍

1. **按类型分组**：`papers` / `public` / `code` / `books`，默认只跑 `papers+code`，
   公开库与书库显式启用（避免默认输出膨胀、token 浪费）。
2. **配置与代码分离**：学校相关值（域名/机构码/网段）全在 `config.local.js`，
   代码与公开文档不含学校信息。
3. **失败隔离**：任一渠道失败不影响其它渠道；未配置渠道自动跳过。
4. **stdout 契约**：`--json` 时 stdout 只有 JSON，所有日志走 stderr。
