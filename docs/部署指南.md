# 校园网资料检索工具 · 重建指南（**通用版**）

[English: deployment.en.md](deployment.en.md)

> 适用：**任意高校**。把本校订购的渠道、入口域名、认证方式填进第 2 节的配置表即可。
> 本文件**不含任何具体学校的域名、账号、出口网段或个人信息**；学校专用细节见同目录 `重建指南-本校专用版.md`。
> 行为规则由部署者自定；技术细节见 `校园网资源检索手册.md`（若随仓库提供）。

---

## 0. 一句话架构

```
find.js（统一入口：解析参数 / 按"分组"选渠道 / 统一输出）
   └── sources/*.js（每渠道一个适配器：定位 → 抽取 → 取链接）
          ├── HTTP 渠道：arxiv.js、github.js
          └── 浏览器渠道：cnki.js、spis.js、opac.js、huya.js、cxstar.js、blyun.js、duxiu.js
   └── chrome.js（受控 Chrome 启停）+ cdp.js（零依赖 CDP 客户端，Node 原生 WebSocket）
   └── config.js + config.local.js + config.example.js（学校相关值，代码里零学校信息）
```

**两个关键设计**：
1. **按类型分组**：`papers`（论文）/ `code`（代码）/ `books`（图书）；默认 papers+code，
   **永远不会自动查书**（书库信息密度低、烧 token，用户明确要书才用 books）。
2. **配置与代码分离**：域名/机构码/网段等全部在 `config.local.js`，换学校只改这一个文件。

**零 npm 依赖**：只用 Node 内置模块（`node:child_process` / `node:fs` / 原生 `fetch` / 原生 `WebSocket`）。
> 之所以手写 CDP：学术站大多要求"真实浏览器页面上下文"（同源 + cookie + 反爬 JS），纯 HTTP 拿不到；
> 而 npm 源不通时装不了 playwright/puppeteer，于是用 Node 原生 WebSocket 直连 Chrome DevTools。

## 4. 部署与冒烟

```bash
cd <本仓库根目录>   # find.js 就在根目录

# Chrome 路径（按需要改）
export LITSEARCH_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"   # macOS
# $env:LITSEARCH_CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"           # Windows PowerShell

export LITSEARCH_PROFILE="$PWD/.chrome-profile"

node find.js --check                       # 校园网 + Chrome + 各渠道体检

# 日常：查论文（默认就是 papers+code，不用写 --src）
node find.js "拓扑绝缘体" --rows=5
node find.js "topological insulator" --rows=5    # SPIS 默认出详情页

# 指定分组
node find.js "拓扑绝缘体" --src=papers --rows=5          # 知网+纬度+百链论文类+arXiv
node find.js "FDTD"       --src=code                     # GitHub
node find.js "topological insulator" --src=public --rows=5   # 公开库（免认证，默认关闭）
node find.js "topological insulator" --src=all --rows=3      # 校内+公开+代码 全量
node find.js "电磁场与电磁波" --src=books --rows=3        # 书库（用户明确要书时才用）

# 单渠道 / 类型过滤
node find.js "拓扑绝缘体" --src=blyun --type=学位论文 --rows=5
node find.js "电磁场与电磁波" --src=huya --rows=3
node find.js "电动力学" --src=duxiu --rows=3
```

> **默认无头后台**（不弹窗）；`--show-chrome` 切有界面（调试用）。受控 Chrome 用完即关，不碰日常 Chrome。

## 5. 统一契约（所有渠道必须遵守）

### 5.1 CLI 参数

| 参数 | 作用 |
|---|---|
| `--src=渠道/分组` | 渠道：cnki/spis/blyun/arxiv/github/opac/huya/cxstar/duxiu；分组：papers/code/books |
| `--rows=N` / `--pages=N` | 条数 / 页数 |
| `--json` | 输出 JSON（**完整 url/detailUrl/articleUrl**，交付链接只能从这里取） |
| `--link=detail` | **默认**：出站内详情页（点开注册 + API 复核）；`--link=article` 改为出版社原文 |
| `--offset=N` | 跳过前 N 条（0 起）；配合 `--rows` 增量翻页，已抓页不重抓 |
| `--no-cache` / `--refresh` / `--cache-ttl=秒` / `--clear-cache` | 结果缓存控制（默认 30 分钟，macOS `~/Library/Caches/litsearch`） |
| `--en` | 中文库切"外文"库检索（如知网） |
| `--type=` | 类型过滤：硕士/博士/期刊/会议/图书/报纸/学位论文（百链、知网） |
| `--field=` | 电子书检索字段：bookname/author/catalog/fulltext（汇雅） |
| `--headless` / `--show-chrome` | 无头 / 有界面 |

**分组默认值**：

| 分组 | 包含 | 用途 |
|---|---|---|
| `papers` | cnki + spis + blyun（论文类）+ arxiv | 查论文（**默认**，只跑校内渠道） |
| `public` | openalex + crossref + doaj + pubmed | **免认证**公开库，**默认关闭**（显式 `--src=public` 才跑） |
| `code` | github | 查代码 |
| `books` | opac + huya + cxstar + blyun（图书）+ duxiu | 查书/教材（**用户明确要求才用**） |
| `all` | papers + public + code | 明确要"扫全"时用 |
| 不给 `--src` | papers + code | **不含公开库、永不自动查书** |

### 5.2 适配器返回字段

```js
{
  source, label, keyword, numFound,
  items: [{
    title, author, source, date, type,
    url,            // 题录/详情页（该渠道自己的）
    pdfUrl,         // OA PDF（有则给）
    articleUrl,     // 出版社原文
    detailUrl,      // 站内详情页
    detailVerified, // 详情页"注册+API 复核"通过（发现类渠道必填）
    // 馆藏专属：publisher, year, isbn, callNo, physicalCount, onShelf, canBorrow, eCount
    // 电子书专属：ssid, kinds, readUrl, cardUrl（汇雅）/ ruid（畅想）
    // 图书检索专属：avail[]（获取方式：馆藏纸本/汇雅电子书/文献传递）, cite（被引）
    // 百链专属：type（图书/报纸/学位论文/会议/期刊）, meta（原文元数据行）
  }],
  onCampus, institution,
}
```

### 5.3 链接与验证规范（硬性）

- 链接**逐字完整复制**，禁止手打/省略/`…` 占位；
- 外部链接：`curl -s -o /dev/null -w "%{http_code}" -L "<URL>"`，200/30x 算通；
- **发现系统的详情页：SPA 的 404 也是 HTTP 200** → 只能看后端接口是否返回正文对象；
- 同域名**抽样验**（curl 1 条 + 浏览器最多 1 条），不逐条开浏览器；
- 详情页验不过 → 退回出版社原文并标 ⚠️，**条目保留**；链接验不过**宁可不给**。

## 6. 通道速查表（按本校实际勾选）

| 渠道类型 | 认证 | 关键点 | 主要坑 |
|---|---|---|---|
| 中文论文库（知网/万方/维普） | 校园网 IP | 结果行选择器 + 机构标识；`groupCode`/`x-lang` 之类 header 缺一不可 | ①`load` 事件极慢（可能 60s）不能等；②英文/长词拆分后乱匹配；③"外文库"常需**点开关**（AJAX，URL 不变）；④无头 UA 可能被 403 |
| 外文发现系统（SPIS 等） | 校园网 IP | 卡片选择器 + 详情 gid；分页常是 AJAX（URL 不变） | ①裸详情链接未"注册"会 404（点开/调注册接口后才长期可开）；②点击标题可能被内联标签吞 → 点偏左；③结果集每次浮动（列表接口与页面卡片仅约 2/10 重合，**不要**用另一次列表接口反查详情字段）；④详情注册：从卡片 DOM 构造 `saveDetail` 载荷批量 POST（实测 8 条 4–5s） |
| 馆藏 OPAC | 免登录 | `POST /find/unify/search` 之类接口，必须带机构码 | ①缺机构码静默 0 条；②"可借数"字段常为 `null`（不是 0）→ 用"在架数"；③多词是 AND，书名+作者易 0 命中 |
| 电子书（汇雅类） | 校园网 IP | 页面检索 + `li.zli_info` 卡片；书名在 `h2 a` 的 title；`ssid` 唯一 | ①阅读链接带**时效签名**，必须当场取；②`/book/detail` 404 → 用 `/book/card` 书目页 + reader |
| 电子书（畅想之星类） | 校园网 IP | **JSON**：页面内 `POST /esapi/Book/Search`；`pinst` 从入口页取 | ①**限流极严**（连发 20 条 → 429 + retry-after 3600，整出口 IP 封 1h）；②书目页 curl 302，浏览器可开 |
| 文献发现（百链类） | 校园网 IP | `searchJour?sw=…&ecode=utf-8`；结果**按类型分组**（`.mpt-main`） | ①不是平铺列表，要按组展开；②元数据行按原文取，硬拆作者/来源易错；③`--type` 过滤 |
| 图书检索（读秀类） | 校园网 IP | **GBK 编码**：页面内建 `accept-charset=GBK` 表单提交；`div.books li` 隐藏字段 | ①UTF-8 传参会乱码；②Node 无 GBK 编码器，必须让浏览器编码；③文献传递需本人邮箱 |
| 预印本（arXiv） | 免认证 | Atom XML，`<link title="pdf">` | 中文关键词必然 0 条 |
| 公开库（OpenAlex） | 免认证 | `api.openalex.org/works?search=`；`select` 只取需要的字段 | 免 key 有共享预算；中文可搜但偏模糊 |
| 公开库（Crossref） | 免认证 | `api.crossref.org/works?query=` | ①含 `component`（补充材料 .s001）要过滤；②多取再截断，否则前几条全是 component |
| 公开库（DOAJ） | 免认证 | `doaj.org/api/search/articles/<词>` | 偶发 5xx（已重试）；只收 OA 期刊 |
| 公开库（PubMed） | 免认证 | 两步：esearch（拿 PMID）→ esummary（题录） | 生物医学为主；中文检索差 |
| 代码（GitHub） | 免认证（限速） | JSON `items[]` | 中文词出刷词垃圾仓库；描述要截断 |

## 7. 新增渠道标准流程

### 7.1 探测（只读，别急着写代码）

1. 浏览器手动完成一次检索；
2. DevTools → Network：找结果数据来源（JSON 接口优先；纯 DOM 记录容器选择器）；
3. 验证认证方式（清 cookie 还能不能用 → IP 认证 or 账号）；
4. 记录分页方式与每页条数。

### 7.2 适配器骨架（HTTP 渠道）

```js
'use strict';
const SITE = 'https://<本站域名>';
async function search(keyword, opts = {}) {
  const url = `${SITE}/api/search?q=${encodeURIComponent(keyword)}&n=${opts.rows || 10}`;
  const res = await fetch(url, { headers: { 'User-Agent': 'litsearch/1.0' } });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const j = await res.json();
  return {
    source: 'xxx', label: '某站', keyword,
    numFound: j.total || 0,
    items: (j.hits || []).map((x) => ({
      title: x.title, author: x.author, source: x.venue, date: x.date,
      url: x.link, pdfUrl: x.pdf || '',
    })),
  };
}
module.exports = { search, SITE };
```

浏览器渠道：复制 `sources/opac.js`（接口型）或 `sources/spis.js`（DOM+注册型）当模板，只改三段：

1. **定位**：`openAndWait()` —— **不要 `cdp.goto` 等 load**；用 `Page.navigate` + 等 `location.href` + `waitFor(结果容器)`；
2. **抽取**：`EXTRACT_JS` 用稳定选择器，返回 JSON 字符串；
3. **取链接**：DOM 直取；需注册/点击的参考 `spis.js` 的 `resolveDetailUrls()`（批量 `Promise.all`）。

### 7.3 注册到入口

```js
const SOURCES = { xxx: { mod: './sources/xxx', browser: false, label: '某站' } };
// optsFor() 里补该渠道专属参数
```

## 8. 通用坑清单（22 条）

1. **绝不等 `load` 事件**（发现系统/知网可能 60s）→ 等 URL + 容器稳定。
2. **接口调用批量 `Promise.all`**（逐条 → 一次 eval；实测 20 条 71s → 6.8s）。
3. **固定 `sleep` 换条件等待**（有上限）。
4. **无头 UA 可能被拦**（403）→ 用本机 Chrome 版本拼普通 UA。
5. **SPA 的 404 不是 HTTP 404**（页面永远 200）→ 用接口判据。
6. **裸链 ≠ 可用**：发现系统记录未"注册"时 404（点开/调注册接口后长期可开）。
7. **点击可能被内联标签吞**（`<b>`/`<span>`）→ 点标题左侧。
8. **同一关键词结果集会浮动** → 同一次运行取全字段，别重跑。
9. **渐进渲染**：READY 只代表第一条 → 等数量连续两次不变。
10. **`null` ≠ 0**：可借数常为 null，`|| 0` 会谎报"可借 0"。
11. **OPAC 多词是 AND** → 只搜书名核心词。
12. **电子书 reader 链接带时效签名** → 当场取；detail 路由可能是 404。
13. **403/429 ≠ 坏链**（反爬）→ 如实标注。
14. **用完必关**：只杀本工具调试端口的 Chrome，不碰用户日常浏览器。
15. **GBK 站点**（读秀类）：Node 无 GBK 编码器 → 页面内建 `accept-charset=GBK` 表单提交。
16. **强限流站**（畅想类）：请求间隔 ≥2.5s；遇 429 立即停（勿重试），批量验证链接会触发封 IP。
17. **结果按类型分组**（百链类）：不是平铺列表，要按 `.mpt-main` 组展开后再过滤/截断。
18. **默认不查书**：书库是最后手段；只有用户明确要教材才 `--src=books`。
19. **元数据别硬拆**：百链/读秀的元数据行格式不统一，宁可按原文展示，不要硬拆作者/来源给错信息。
20. **公开库中文噪声大**：Crossref/DOAJ 会把中文词拆开模糊匹配，命中数虚高 → 中文主题优先知网/纬度/百链。
21. **Crossref 有 component 记录**（补充材料 DOI 以 `.s001` 结尾）：不过滤的话前几条全是补充材料。
22. **出版商链接 403 ≠ 坏链**：MDPI/Wiley 等对脚本 403，浏览器能开；按规则如实标注。

## 10. 跨平台与浏览器

**已内置跨平台处理**（`chrome.js`）：

| 能力 | 说明 |
|---|---|
| 浏览器自动探测 | macOS：Chrome / Edge / Chromium / Brave；Windows：`%ProgramFiles%\Google\Chrome\Application\chrome.exe` 等 + Edge/Chromium/Brave；Linux：`google-chrome`/`chromium`/`microsoft-edge`/`brave-browser` |
| 手动指定 | `LITSEARCH_CHROME=<可执行文件路径>`（任何 Chromium 内核浏览器都行） |
| 停止进程 | 启动时写 `.chrome.pid`，停止按 PID 杀（macOS/Linux `kill`，Windows `taskkill /PID`）；兜底按调试端口查找 |
| 无头 UA | 版本号按平台获取（macOS/Linux 调 `--version`；Windows 读安装目录版本子目录），并伪装成对应平台 UA |
| Windows 细节 | `spawn` 已加 `windowsHide:true`；终端中文乱码请 `chcp 65001` |

**支持矩阵**：

| 平台 / 浏览器 | 状态 |
|---|---|
| macOS + Chrome / Edge / Chromium / Brave | ✅ 实测可用 |
| Windows + Chrome / Edge | ✅ 代码已适配（**未实机验证**，如有问题按下面排查） |
| Linux + Chromium 系 | ✅ 代码已适配（未实机验证） |
| Firefox / Safari | ❌ 不支持（不走 CDP；需要另写 WebDriver 驱动层） |

**Node 版本**：所有平台 **≥ 22**（`cdp.js` 依赖原生 WebSocket 与 `fetch`）。

**Chrome profile 默认放系统临时目录**（`os.tmpdir()/litsearch-chrome-profile`），
这样即使工具目录在只读位置（如别的 agent 工作区无法写 `~/litsearch`），浏览器仍能启动；
可用 `LITSEARCH_PROFILE` 指定其他可写目录。

**Windows 排错**：
1. `node find.js --check` 看是否找到浏览器；
2. 找不到 → 设 `LITSEARCH_CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"`；
3. 关不掉浏览器 → 检查 `taskkill` 是否可用（系统自带）；
4. 中文乱码 → `chcp 65001` 后再跑。

## 11. 依赖边界与安全

- **公开库（OpenAlex/Crossref/DOAJ/PubMed）完全免认证**；校内渠道只依赖校园网 IP，不依赖任何账号密码（知网/纬度/百链/读秀/汇雅/畅想/OPAC 均如此；arXiv/GitHub 免认证）；
- 代码里**没有硬编码账号、密码、cookie、token**；`GITHUB_TOKEN` 只从环境变量读；
- 受控 Chrome 用**独立 profile**，不读取你日常浏览器的登录态；
- **不读取**任何系统凭据文件（登录脚本、keychain 之类）；
- 分享时**不要**打包 `.chrome-profile/` 与备份包（可能含会话 cookie）。
